Shopify opened its catalog, cart and checkout to AI agents on Oct 28, 2026. That raises a plain question for anyone selling online: can an agent actually find your products and buy them? This free check walks through the five places that answer usually breaks — about 15 minutes, each one pass or fail.

The five checks

  • 1. UCP discovery profile — the /.well-known/ucp file an agent looks for first.
  • 2. Machine-readable catalog — products.json plus structured data an agent can parse.
  • 3. llms.txt + agent knowledge base — a plain-language map of your store for AI systems.
  • 4. A /buy link that lands in checkout — no dead ends between discovery and payment.
  • 5. Agent purchase with buyer approval — an agent can complete a purchase, with the buyer approving it.

I ran it on my own store first: 4 pass, 1 partial. Your numbers will be your own — that’s the point of running it.
